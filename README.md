# Machine Learning Prediction of CoCrNi Alloy Properties

This repository contains a machine learning workflow for predicting the mechanical properties of CoCrNi medium-entropy alloys using compositional and processing parameters. The project focuses on predicting Yield Strength, Ultimate Tensile Strength (UTS), and Elongation through multi-output regression models trained on experimental alloy datasets.

## Objective

The primary goal of this project is to explore the application of materials informatics and machine learning in alloy property prediction. The workflow demonstrates how data-driven approaches assist in reducing experimental effort and accelerating alloy development.

## Features

* Multi-output regression for simultaneous prediction of:

  * Yield Strength
  * Ultimate Tensile Strength (UTS)
  * Elongation
* Exploratory Data Analysis (EDA)
* Correlation heatmaps and feature analysis
* Gaussian noise-based data augmentation
* Random Forest and Gradient Boosting regression models
* Model evaluation using:

  * R² Score
  * Root Mean Square Error (RMSE)
* Prediction and comparison visualisations
